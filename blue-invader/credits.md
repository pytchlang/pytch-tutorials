## Project assets

- `enemy-alien.png`, `friendly-alien.png` — The two space-invader
  images are based on ["Space invaders character
  4"](https://commons.wikimedia.org/wiki/File:Space_invaders_character_4.jpeg),
  which is copyright Wikimedia user アロたん.  We use that image under
  the [Creative Commons "CC BY-SA 4.0"
  licence](https://creativecommons.org/licenses/by-sa/4.0/).  We have
  split the original image into two, tidied up some JPEG artifacts,
  and changed the colours.

- `explosion.mp3` — The explosion sound effect is based on [an
  original](https://freesound.org/people/derplayer/sounds/587193/) by
  [Freesound user
  "derplayer"](https://freesound.org/people/derplayer/), who has
  placed it into the public domain.  We have trimmed it.

- `fizz.mp3` — The fizz sound effect is based on [an
  original](https://freesound.org/people/odilonmarcenaro/sounds/238564/)

  We use it under the [Creative Commons CC BY 3.0
  licence](https://creativecommons.org/licenses/by/3.0/).  We have
  trimmed it and speeded it up.

- `scream.mp3` — The scream sound effect is based on [an
  original](https://freesound.org/people/redafs/sounds/348310/)

  "redafs"](https://freesound.org/people/redafs/).  We use it under
  the [Creative Commons CC BY 3.0
  licence](https://creativecommons.org/licenses/by/3.0/).  We have
  trimmed it.

- `special-alien.png` — The red alien image was adapted by the Pytch

  It is used under the [Creative Commons
  Sharealike](https://creativecommons.org/licenses/sa/1.0/) licence.
  (Note that Creative Commons no longer recommends this licence for
  new works, but nonetheless it is the one under which we use this

- `starry-sky.jpg` — The [night sky
  photo](https://unsplash.com/photos/LUpDjlJv4_c) is copyright
